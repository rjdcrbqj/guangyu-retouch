# 光屿修图

Windows 本地修图工作台。照片在本机处理，目前正在持续补齐功能。

## 0.18.0

完成人像抠图后，可应用纯色或选择本地 JPG、PNG、WebP 背景照片。背景照片等比铺满画面，可缩放和移动取景。切回透明时保留现有抠图。背景替换随每张照片的工程和编辑历史保存，适用于原尺寸单张和批量导出。

含背景替换或替换历史的工程需要 0.18.0 或更新版本打开。

## 0.17.0

打开“抠图”，选择“自动移除背景”。需要修边时可补选人物、擦除多余区域或显示背景作参考。单张和批量导出均保留原尺寸，PNG 支持透明背景，JPG 使用白底。逆光、细发丝和贴近人物的物体可能需要手动修边。

含抠图蒙版或抠图历史的工程使用格式 7，需要 0.17.0 或更新版本打开。

## 0.16.0

在“唇色”选择颜色并调节强度。可与淡化唇纹叠加，支持原图对比、撤销、工程保存、唇部预设、批量同步和原尺寸导出。强度默认 0，批量处理在每张目标照片上独立定位。强度较高时，个别照片可能看出唇缘定位边界。含唇色效果的工程和预设需要 0.16.0 或更新版本打开。

## 0.15.0

在“输出设置”选择文字或图片水印。文字可设置颜色，透明 PNG 可用于图片水印。五个位置、大小和不透明度设置同时用于单张和批量导出。水印按透视与液化之后的最终照片定位，保留输出原尺寸。选择“无”关闭水印。设置在当前工作台会话中有效。

## 0.14.0

选择“液化”，调节笔刷半径，在照片上拖动局部轮廓。松手应用一笔，可撤销、清除或按 Esc 取消当前笔划。液化可以和四点透视叠加，按每张照片保存，并用于原尺寸单张及批量导出。

含液化笔划或液化历史的工程使用格式 6，需要 0.14.0 或更新版本打开。旧工程仍可打开。超窄照片及纹理容量有限的设备可能无法显示部分笔划，打开工程时会提示并保留原笔划。

## 0.13.0

打开“四点透视”，将四角拖到要拉正的平面边缘，再点击“应用”。可对比原图、撤销、清除和保存工程。单张和批量导出使用每张照片自己的四角，输出保持原尺寸。含透视点位或透视历史的工程使用格式 5，需要 0.13.0 或更新版本打开。旧工程仍可打开。

超长图修正了图块行边界的采样错误。透视校正保留 PNG 的透明边缘，原尺寸处理能力取决于设备显存。

## 0.12.0

虹膜调色提供画面左右眼独立强度和共用色相、饱和度，默认关闭。使用公开眼部定位，在原尺寸保留虹膜明暗纹理、瞳孔中心和反光，深色虹膜的变化较轻；支持最多8张脸、原图、归零、历史、工程、眼部预设、批量和原尺寸输出。闭眼、不可靠定位会跳过，复杂镜片、偏头、极小虹膜仍需检查；这是独立颜色修饰，不是原版算法或美瞳材质生成。旧眼部预设补新强度0，0.11.0安装包尚不包含此项。

红眼消除已加入当前照片编辑流程：默认强度为0，增加强度后处理闪光形成的红色瞳孔，保留高光、透明度和眼外区域。支持最多8张脸、撤销、工程保存、眼部分组预设、批量重新定位及原尺寸输出。闭眼和不可靠定位不会强行处理；极小瞳孔、严重偏头、彩色镜片或复杂反光仍可能漏检。使用既有公开定位模型及独立像素修饰，不宣称与原软件一致，也不适用于宠物发光眼。已发布的0.11.0安装包尚不包含此项。

## 0.11.0

大图查看已按原图物理像素计算倍率，100%表示一个照片像素对应一个屏幕物理像素。细节查看和原尺寸导出使用同一处理链；超长边照片分块保留原像素，适应窗口、切图和取消准备会释放细节资源。已验证横纵长图及两种8000万像素形状，实际可处理尺寸仍受设备显存限制。这些改动自0.11.0起提供。

发丝柔顺使用现有公开模型识别整张照片的头发，不要求找到人脸；“柔顺”和“发丝细节”可独立调节。归零、原图对比、撤销、工程、批量同步、预设和原尺寸输出已接入，识别失败保留上次结果。极细发丝、帽子或遮挡仍可能影响识别，效果不宣称与原软件一致。

去白发提供独立强度。自动模式侧重细白丝，灰白发较多时可选择“重建发色”，按各片头发自己的深色参考整体加深并保留明暗纹理；此模式适合确为灰白发的照片。高光、浅色染发和遮挡仍可能影响结果。原图、归零、撤销、工程、批量、预设及输出保持可用，早期两项发丝参数的预设继续可读。

## 公开替代版本

美牙、亮眼、HSL、色温、色调、暗角和细节效果使用独立公式；照片内的净肤、祛皱、去眼袋、祛黑眼圈、淡化唇纹及肤色统一使用公开定位、分区和本地修饰。此版本不携带原软件私有权重或原着色资源，效果与原软件不宣称逐像素一致。

旧美牙投影缓存、旧亮眼 v1/v2 缓存、旧参数和历史工程保持可读。覆盖升级先完整暂存新版，再切换程序文件；旧程序资源保存在安装目录同级的 `*.guangyu-backup-*` 文件夹中。照片、工程和用户设置保留，升级失败时恢复旧程序。备份由用户自行决定何时移除。

源码归档只包含干净运行源码、公开模型及其许可证和构建文件，不包含本机研究目录、测试照片、私有权重或本地 Git 历史。

## 从公开源码运行

完整源码归档包含模型；通过 Git 或 Code 下载获得代码时，请先按 [完整源码与模型](SOURCE_BUNDLE.md) 还原公开模型文件。

需要 Windows 10/11 64 位、Node.js 和 Python。解压源码后，在项目目录安装开发依赖，在 `inference` 目录按锁定记录安装图像处理依赖，然后启动：

```powershell
npm install
npm ci --prefix inference
npm start
node --test tests/*.test.mjs
```

安装包构建还需要 NSIS。把 Electron 运行环境放在项目的 `runtime` 目录，使用新的暂存与构建目录；脚本拒绝覆盖旧输出。分发前须核对模型记录、实际程序文件和源码归档，不能仅检查模型扩展名。

```powershell
python tools/public_release.py dist/public-stage
python tools/public_release.py dist/public-build --build-from dist/public-stage --version 0.18.0
python tools/public_release.py dist/GuangyuRetouchSource.zip --source-from dist/public-build/payload/resources/app --version 0.18.0
```

## 更新

从 0.8.1 起，软件启动后及运行期间会检查 GitHub 的正式发行版。发现新版后显示更新内容，由使用者选择是否下载、是否安装并重启。也可以使用窗口右上角的“检查更新”。

安装前请保存工程。更新覆盖原安装目录，保留本机快捷键和用户数据。0.7.x 首次升级需下载安装 0.8.1 或更高版本，此后即可使用内置更新。

## 使用

- 鼠标放在照片区域，直接滚动滚轮放大、缩小；也兼容 Ctrl＋滚轮。
- 0：适应窗口；1：100% 查看。
- 底部照片栏切换照片；勾选目标照片后，在右侧“批量”中选择“已调整”或全部参数进行同步。
- Ctrl＋Z / Ctrl＋Shift＋Z：撤销、重做当前照片。
- Ctrl＋Alt＋Z / Ctrl＋Alt＋Shift＋Z：全局撤销、重做，可恢复照片切换和整组同步。
- 保存工程会保留最近20个单图状态；全局历史仅保留当前会话。
- 顶部“快捷键设置”：修改、清除或恢复功能快捷键。

AI 净肤、祛皱、去眼袋、祛黑眼圈、淡化唇纹、肤色统一在当前照片上处理，松开滑杆自动应用；归零可移除效果。原图对比、撤销、工程保存、批量同步和新预设均保留这些效果。

旧工程继续可读；含 AI 图像或其撤销历史的工程需使用 0.9.0 及以上版本。参考肤色已接入当前照片效果链，支持强度调整、归零、撤销与保存；其参考蒙版和效果使用格式3，0.9.0及更早版本会拒绝打开。参考同步和新版预设使用目标自己的皮肤选区，预设包含64×64取色块及参考蒙版。全部功能和模型效果尚未与像素蛋糕完全一致。

开发版的构建和发布现在会检查模型分发记录 `tools/model-distribution.json`，同时核对源目录、已有打包缓存和随包许可文件。目前已接入 MIT 许可的 YuNet 找脸（含倾斜回退）和 Apache 2.0 许可的 MediaPipe 头发分区替代模型，均在本机运行；皮肤自动选区和手动框脸已结合公开 Face Landmarker 的 478 点，保护双眼、眉毛与嘴部；定位失败保留原选区。嘴唇和眉毛也已改用公开面部轮廓方案；增加独立五点交叉检查以拒绝眼口误定位，478 点在六张样片中五张通过、一张侧脸拒绝；嘴唇现增加 BSD 2-Clause 许可的 OpenSeeFace 66 点备用定位，使该侧脸也能生成嘴唇选区，皮肤和眉毛仍拒绝不可靠结果，尚不代表完整语义分割质量。自动牙齿已使用公开口腔定位与颜色筛选，沿用牙齿美白和普通选区流程；它仍会漏选部分边缘牙齿，不等同于完整语义分割。智能点选已使用公开 MagicTouch V2，新照片无需原版特征缓存；亮眼新识别已改用公开定位、实际眼区可见性检查及独立修饰公式，保留左右眼总强度、眼白、瞳孔与高光控制；含新亮眼缓存或其历史的工程使用格式4，旧程序会明确拒绝，旧亮眼缓存仍可读取。祛黑眼圈已改用公开定位与皮肤分区、邻近皮肤明暗和色差校正，保留原图细节、透明度、当前照片流程与原有工程格式；它仍可能漏修侧光或遮挡，不等同于原版网络。去眼袋也已使用公开定位、皮肤分区与独立局部明暗校正，卧蚕保留可单独调整，并能与祛黑眼圈连续组合；几何保护带与复杂眼袋质量仍需完善。淡化唇纹已接入公开定位与独立纹理修饰。松开滑杆后减淡唇面可辨认的细沟，归零恢复，低分辨率和遮挡场景可能跳过。肤色统一现以每张脸自己的皮肤颜色为参考，减轻局部色偏，并保留明暗起伏，眼、眉、唇区域受到保护。净肤已改用公开定位和局部斑点修饰，保留三个强度与独立淡化痣开关；复杂妆容和相连斑点仍可能误判。祛皱支持整体与九个分区，使用公开面部定位、皮肤选区及独立的方向性纹路处理。六类当前照片效果现已接入公开替代；独立的参考肤色现使用选中皮肤和取色块的颜色统计，在本机校正色差，保留原图的明暗层次。安装包仍须从干净目录构建并通过分发检查。此检查不删除或执行本机模型。可运行 `python tools/release.py audit-models`，在 `dist/model-distribution-audit.json` 查看未获准条目。模型来自原版恢复或研究候选，不等于已取得公开分发许可；旧安装缓存也包含这类文件，不能直接沿用旧缓存继续发布。
